# RadioTelescope-ATLAS

A 1 m-class hydrogen-line radio telescope built from laser-cut wood ribs and 3D-printed parts. The reflector is a parabolic dish (focal length 40 cm) assembled from 18 radial wooden ribs, 3 mm thick, seated in a printed base mount.

## Status

Design phase. The rib base mount is modeled and awaiting its first print.

## Base Mount

- 18 radial slots, 3.52 mm wide, for 3 mm wood ribs (0.52 mm total clearance)
- Rib dimensions taken from physically cut parts
- Designed for FDM printing
